# Coark YC demo scenario

Coark YC 제품 데모 시나리오를 공유하는 정적 웹페이지입니다.

- 상황과 행동 설명은 한글, 대사와 채팅 및 화면 문구는 영어로 구성합니다.
- 대화에서의 업무 합의, 자동 티켓 생성, 공동 AI 세션, 동료 참여, 결과 문서 보존, 후속 대화에 따른 변경을 7개 장면으로 담았습니다.
- 가상의 서비스 출시 사례를 사용한 시나리오이며 기능 구현 상태를 나타내는 문서는 아닙니다.

GitHub Pages에서 `main` 브랜치의 루트 디렉터리를 배포합니다. 내용 변경은 `index.html`에 반영합니다.
